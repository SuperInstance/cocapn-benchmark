# ⚡ cocapn-benchmark

Cocapn fleet benchmark module — performance testing, regression detection, and capacity planning.

## Install

```bash
pip install cocapn-benchmark
```

## What It Does

Benchmarking utilities for fleet services and agents. Performance testing, regression detection, and capacity planning.

### Key Features

- **Service Benchmarks** — Throughput and latency testing for all fleet services
- **Agent Benchmarks** — Response quality and speed scoring
- **Regression Detection** — Catch performance regressions automatically
- **Capacity Planning** — Resource usage projections

## Part of the Cocapn Fleet

- [cocapn-telemetry](https://github.com/SuperInstance/cocapn-telemetry) — Metrics collection
- [cocapn-dashboard](https://github.com/SuperInstance/cocapn-dashboard) — Live dashboard
